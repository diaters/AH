# Demo Skill

This is a demonstration skill contributed by the `harness-demo` plugin.

## Capability

- Observe all 21 hook points in the plugin system
- Provide `echo` and `query_tasks` tools for LLM agents
- Demonstrate `tool_deny`, `tool_set_result`, `create_task`, and other host APIs

## Usage

When you need to echo a message or query the current task state, use the
`harness-demo:echo` or `harness-demo:query_tasks` tools.
