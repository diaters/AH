A：三栏布局

左栏 Agent 列表，中栏对话区，右栏任务/审批。信息密度最高，适合大终端。

优点

  • 一屏看清全局状态
  • 任务和审批信息常驻可见

缺点

  • 窄终端（<100列）体验差
  • 三栏信息量对简单任务过重

B：双栏 + 底部输入

左栏对话区（含审批卡片），右栏 Agent/任务状态。审批嵌入对话流。

优点

  • 对话体验更沉浸
  • 适应中等终端（≥80列）

缺点

  • 审批信息需滚动查找
  • 任务状态面板空间有限

C：Tab 切换布局

单栏全屏，通过 Tab 键切换 Chat/Agents/Tasks/Approvals 视图。

优点

  • 全屏展示各视角，信息最充足
  • 窄终端也完全可用

缺点

  • 无法同时看对话和状态
  • 需频繁切换 Tab
